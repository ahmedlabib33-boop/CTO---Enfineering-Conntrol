# Engineering Rules

Rules live in `engineering-rules/default.yaml`.

Core controls:
- preserve uploaded originals;
- preserve layer semantics;
- classify changes A/B/C;
- require user confirmation for A/B;
- Class C requires engineering approval;
- never treat generic reference knowledge as project authority;
- unresolved/unsupported cases must be surfaced, not silently accepted.

The rule set is intentionally conservative for the MVP.
