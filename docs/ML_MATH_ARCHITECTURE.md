# ML + Mathematical Intelligence Architecture

The platform uses a hybrid decision stack:

1. **Project evidence and authority** — contract, approved design, RFIs, instructions and revision status.
2. **Exact mathematics / constraints** — geometry, symbolic algebra, graph algorithms, SAT/SMT/CP optimization where the problem is formalizable.
3. **Deterministic engineering rules** — Class A/B/C, hard safety and approval gates.
4. **Machine learning** — entity matching, classification, anomaly detection, ranking, confidence, document/image/object recognition and learned patterns.
5. **Human engineering review** — reviewed decisions become training labels; unreviewed predictions do not.

## Learning loop

Reviewed change → feature extraction → project-scoped example store → retrain/version → probabilistic recommendation → confidence gate → deterministic authority check → human decision → new reviewed example.

ML output is advisory. It may increase attention or suggest a class; it cannot downgrade a Class C engineering approval requirement.
